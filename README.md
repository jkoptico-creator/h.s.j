# 호주 여행 제안

2026년 11월 여행을 위한 다섯 가지 대안입니다. 공개 사이트의 시각·요금은 예약 확정표가 아니라 계획 수립용 제안입니다.

## 편집

- `index.html`: 개요·비교표
- `plan-1-*.html` ~ `plan-5-*.html`: 각 여행안의 원본
- `assets/site.css`, `assets/site.js`: 공통 화면과 동작
- `assets/places.js`: 장소별 사진과 공식 정보·지도
- `assets/photos/`: 출처를 확인해 저장한 사진과 `sources.json` 출처 목록
- `review/`: 미검증 사진 후보 시트. 검색 제외 설정이며 접근 통제 기능은 아닙니다.

`호주여행제안.html`은 생성 파일입니다. 직접 편집하지 않고 개별 페이지·공통 파일을 수정한 뒤 아래 명령을 실행합니다. Python 표준 라이브러리만 사용합니다.

```text
python scripts/build_combined.py
python scripts/check_site.py
node --check assets/site.js
node --check assets/places.js
```

화면 동작의 DOM 회귀검증은 `npm ci` 후 `npm test`로 실행합니다. 사진 서버 접근이나 실제 화면 크기의 시각 검증은 별도로 필요합니다.

통합본은 스타일·스크립트를 포함하므로 HTML 한 파일로 공유할 수 있습니다. 저장된 사진도 통합본에서는 공개 사이트의 절대 주소로 불러오므로 사진과 웹 폰트에 인터넷 연결이 필요합니다. 통합본에는 현재 안/전체 안 인쇄 버튼이 있습니다.

## 수정 기준

확인한 운영 정보와 여행자의 실제 예약 상태를 구분합니다. 날짜별 운항·티타임·객실·투어 재고를 확인하지 않은 경우 확보됐다고 쓰지 않습니다. 차량 이동 예상치와 수하물·대기·주차 시간을 구분하고, 동시 수행이 어려운 체험은 대체 선택지로 표시합니다. 사진을 불러오지 못하면 다른 장소 사진으로 바꾸지 않습니다.

2026-10-19 검토와 수정 내용은 `docs/review-changes.md`를 참고하세요.
사진 교체 내역과 원본 출처는 `docs/photo-sources.md`를 참고하세요. 갤러리의 현재 사진 설명과 출처는 `window.PHOTO_SOURCES`에서 관리합니다.
